## Review and changes

The review covered Outline, Chronology, Sequence, Refine, Choices (subsequently retired at the user’s request), Characters, World, Connections, and Archive at desktop and phone sizes, plus the character, World, and connection editors. Isolated sample stories supplied populated states; no user stories were modified.

- **Readable titles:** outline title fields wrap and grow instead of hiding most of the title behind action icons. Enter saves the title, and resizing recalculates its height. Phone actions occupy a separate compact row; drag handles, selection, folding, and every existing action remain available.
- **Aligned beats:** beats advancing the same outer thread keep the same left edge after dragging. The previous measurement captured the temporary scale of the drop animation, then retained that false offset. Alignment now uses layout coordinates, independent of transforms on a beat or its containing threads.
- **Relevant character timeline stops:** the character view omits retained timing anchors for archived or permanently deleted outline pieces, including placeholders already present in saved stories. Explicit standalone chronology moments remain visible. Removing the currently selected stop returns the character view to the beginning; restoring a thread brings its stops back. The underlying chronology and archived state changes are preserved.
- **One Milieu context row:** people, settings/cultures, and other linked World entries share one wrapping row. Settings appear once, with their existing open, unlink, and link controls together; the redundant setting heading and repeated generic World chip are removed.
- **Clear state editing:** type comes before state, with a bounded searchable picker, keyboard navigation, and reusable custom labels. Labels persist through recorded states and forks. Event fields follow Before → Disruption → Resolution. Outline, inspector, and Refine use the same Add change editor, with the full character and consequence options retained inside it.
- **Named actions:** bare plus controls become short action labels; the duplicate inspector change button is removed. Fork, Add outcome, Add state, Add note, and Add change have distinct names.
- **Refine layout:** the planning workspace uses the available width, with moment navigation beside the plan, opening/closing controls before state fields, and grouped optional questions.
- **Recognizable block choices:** linked-block menus include state wording, with a full prior-state preview so same-type beliefs can be distinguished.
- **Choices retired:** the Choices tab is removed, former navigation opens Refine, and all saved goals, decisions, gains, costs, and other craft notes remain editable. The renderer remains available behind a disabled feature switch.
- **Less navigation friction:** the selected story tab stays visible when returning from another page or resizing. Sequence and Chronology disable movement beyond either end of the list. Counts use singular/plural labels correctly.
- **Compact editing:** Refine puts opening/closing selection and Record a change on one row. Its headings and related-content spacing are tighter. The outline inspector groups type, plot membership, and status, with secondary tools arranged together.
- **Consistent library cards:** character blocks, World cards, and connection cards use tighter spacing. The large add-block tile becomes a compact row with the same action. The square portrait is retained.
- **Clearer dialogs:** phone dialogs place Help/Tutorials alongside the eyebrow and give the heading a full row. History and Used here have an explicit action group. Collapsible sections and field spacing are more consistent.
- **Accessibility:** editable state controls use 16px text on phones; focus indicators remain visible. A faint tray label has stronger contrast. The floating tray retains its layout, position, and behavior.

This pass changes presentation and existing-control behavior. It preserves story features and the saved data format; it does not touch account/authentication behavior.
