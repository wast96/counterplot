# Working preferences

- Unless the user says otherwise, complete repository changes by committing and pushing the work, creating a pull request, and merging it into the default branch after required checks pass.
- After a successful merge, delete the task's remote and local working branches and return the checkout to the updated default branch. Never delete the default branch or unrelated branches.
- Do not stop at local edits or ask again for permission to push, merge, or clean up the merged task branch. If checks, permissions, or merge conflicts block completion, resolve them when possible and report any remaining blocker.
